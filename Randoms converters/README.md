## Libraries & Install Commands

Install everything at once:

pip install pywin32 img2pdf pypdf


Or install individually:
- **pywin32** (`win32com.client` — Word & PowerPoint to PDF):

  pip install pywin32
  
- **img2pdf** (Images to PDF):

  pip install img2pdf
  
- **pypdf** (Merge PDFs):

  pip install pypdf
  
bash them in terminal
