## Libraries & Install Commands

Install everything at once:

RUN THE BATCH FILE INSTALL BATCH TO DOWNLOAD EVERYTHING OR FOLLOW BELOW

pip install pywin32 pypdf pymupdf pillow pytesseract opencv-python numpy torch transformers


Or install individually:

- **master.py** (Auto-installs everything on its own)

- **word to pdf.py** / **pptx to pdf.py** / **excel to pdf.py** / **pdf to word.py**:

  pip install pywin32 pymupdf pytesseract pillow

- **jpg to pdf.py**:

  pip install pymupdf pytesseract pillow

- **ocr.py**:

  pip install pymupdf pytesseract pillow opencv-python numpy torch transformers

- **merge pdf.py**:

  pip install pypdf pymupdf pytesseract pillow

- **split pdf.py**:

  pip install pypdf

- **compress pdf.py**:

  pip install pymupdf pillow

- **edit pages.py**:

  pip install pymupdf numpy

- **pdf to images.py** / **text to pdf.py** / **protect pdf.py** / **watermark pdf.py**:

  pip install pymupdf

- **image converter.py**:

  pip install pillow

bash them in terminal
